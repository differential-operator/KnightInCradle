# KnightInCradle
A mod that allows you to switch between Little Knight and Noel
====================================
 小骑士模组（KnightInCradle）安装说明
====================================

【重要】请确保您的 AliceInCradle 版本为 029j，否则模组将无法正常运行！

1. 确保游戏已安装 BepInEx（如果游戏还没有 BepInEx 文件夹，请先安装 BepInEx 5.4 到游戏目录）。
2. 把本压缩包内的 BepInEx 文件夹整个复制到游戏根目录（与 AliceInCradle.exe 同级），
   提示合并/覆盖时选“是”。安装后的目录结构应为：

   AliceInCradle.exe
   BepInEx/
     plugins/
       KnightInCradle.dll
       KnightInCradle/
         assets/...
         键位.txt

3. 启动游戏，按 T 键即可切换出小骑士（默认键位见下方）。

改键位：
用记事本打开 BepInEx/plugins/KnightInCradle/键位.txt，
按“能力：键位”的格式修改，保存后重启游戏生效。
键位名称对照表写在文件开头（如 空格 / 鼠标左键 / 鼠标右键 / 左Shift 等）。

默认键位：
左=A 
右=D
跳跃=W
聚集=C
法术=S
上=Q
下=鼠标右键
冲刺=Shift
攻击=鼠标左键
梦钉=空格
交互=F
超级冲刺=Ctrl
切换角色=T

[Important] Please make sure your AliceInCradle version is 029j, otherwise the mod won't work properly!

1. Make sure the game has BepInEx5.4.23.5 installed。
2. Copy the whole BepInEx folder from this zip package into the game's root directory (same level as AliceInCradle.exe). The directory structure after installation should look like this:

   AliceInCradle.exe
   BepInEx/
     plugins/
       KnightInCradle.dll
       KnightInCradle/
         assets/...
         键位.txt

3. Start the game, press the T key to switch out the knight (default key can be changed)。

Change Key Bindings:  
Open BepInEx/plugins/KnightInCradle/keybindings.txt with Notepad,  
modify the keys in the format 'Ability: Key', save the file, and restart the game for the changes to take effect.  
The key name reference table is written at the beginning of the file (like Space / Left Mouse Button / Right Mouse Button / Left Shift, etc.).

Default key layout:
Left=A
Right=D 
Jump=W
Gather=C 
Spell=S
Up=Q
Down=RightMouse Button
Sprint=Shift
Attack=Left Mouse Button
Dream Nail=Space 
Interact=F 
Super Dash=Ctrl
Switch Character=T
